Recursion
= calculate everything again

Memoization
= recursion + store answers

Tabulation
= bottom se answers build karo

---------------------------------

1. Fibonacci Problem
F(0) = 0
F(1) = 1

F(n) = F(n-1) + F(n-2)

Example:
F(5) = 5
0  1  1  2  3  5
---------------------------------

2. Recursive
Idea: Directly follow the recurrence.
int fib(int n) {
    if(n <= 1) return n;

    return fib(n-1) + fib(n-2);
}

Problem
Same subproblems calculate repeatedly.
fib(5)
 ├── fib(4)
 │    └── fib(3)
 └── fib(3)   ← repeated

Time  = O(2^n)
Space = O(n)   // recursion stack
---------------------------------

3. Memoization = Top-Down DP
Idea: Recursion + store already calculated answers.
int fib(int n, vector<int>& dp) {
    if(n <= 1) return n;

    if(dp[n] != -1)
        return dp[n];

    dp[n] = fib(n-1, dp) + fib(n-2, dp);

    return dp[n];
}

Call:
vector<int> dp(n+1, -1);
fib(n, dp);

Flow
F(n)
 ↓
Need F(n-1), F(n-2)
 ↓
Already calculated?
 ├── YES → dp[] se return
 └── NO  → calculate → store in dp[]

Time  = O(n)
Space = O(n) dp + O(n) recursion
      = O(n)
---------------------------------

4. Tabulation = Bottom-Up DP
Idea: Base cases se start karke answer build karo. No recursion.
int fib(int n) {
    if(n <= 1) return n;

    vector<int> dp(n+1);

    dp[0] = 0;
    dp[1] = 1;

    for(int i=2; i<=n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }

    return dp[n];
}

Flow
dp[0] → dp[1] → dp[2] → dp[3] → ... → dp[n]

Time  = O(n)
Space = O(n)
---------------------------------

🔥 Remember
Recursive
= calculate again and again

Memoization
= Recursion + Store answers

Tabulation
= Iteration + Store answers
---------------------------------

6. DP ka Core Concept
DP tab useful hota hai jab:
1. Problem smaller subproblems mein break ho
             +
2. Same subproblems repeat ho rahe ho

Then:
Calculate once
     ↓
Store answer
     ↓
Reuse answer


Bas Fibonacci se DP ka skeleton yehi hai. Baaki DP questions isi skeleton ko alag situations mein ghuma-phira ke hai !!
